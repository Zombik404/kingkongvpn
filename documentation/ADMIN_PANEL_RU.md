# Админ-панель KingKong VPN

Адрес: `https://<ваш-домен>/admin/`. Это веб-страница для вас и помощников: пользователи,
доступ, платежи, тарифы, промокоды, серверы, блэкджек, настройки и журнал всех действий.

## Вход

1. При установке `install.sh` спрашивает вашу почту и создаёт аккаунт суперадмина. В конце
   установки показывается **одноразовый пароль** — сразу войдите им.
2. При первом входе панель попросит включить двухфакторную защиту: отсканируйте QR-код в
   Google Authenticator, Aegis или 1Password и введите 6 цифр. Без этого админка не откроется.
3. Дальше вход: почта, пароль, код из приложения.

Новый пароль (если забыли) — на сервере:
`cd /opt/globalvpn/deploy && docker compose -f docker-compose.prod.yml --env-file .env.prod exec backend python -m app.cli create-staff ваша@почта superadmin`

Помощника добавляют той же командой с ролью `support`, `ops` или `finance`. Почта может быть
любой вашей: писем мы не отправляем, это просто логин.

Безопасность: ключи входа хранятся только в памяти вкладки — после перезагрузки или через
30 минут без действий нужно войти снова. Можно разрешить вход только с ваших адресов:
`ADMIN_ALLOWED_IPS="ваш.ip/32"` в `deploy/.env.prod`, затем снова `install.sh`.

## Роли

| Что можно | поддержка (`support`) | сервера (`ops`) | финансы (`finance`) | суперадмин |
|---|:-:|:-:|:-:|:-:|
| Смотреть пользователей, обзор | ✓ | ✓ | ✓ | ✓ |
| Продлить / отозвать доступ, заблокировать | ✓ | | | ✓ |
| Платежи и выручка | ✓ | | ✓ | ✓ |
| Тарифы, цены, промокоды | смотреть | смотреть | ✓ | ✓ |
| Серверы и локации | смотреть | ✓ | | ✓ |
| Блэкджек: столы, бонусные дни | смотреть | ✓ | | ✓ |
| Настройки | смотреть | ✓ | смотреть | ✓ |
| Журнал действий | | ✓ | | ✓ |
| Роли сотрудников | | | | ✓ |

Панель показывает только разделы и кнопки, доступные роли; сервер проверяет права ещё раз.

## Разделы

- **Обзор** — пользователи, у кого есть доступ, льготный период, устройства, серверы, выручка
  за 30 дней (если есть право на платежи), графики регистраций и оплат.
- **Пользователи** — поиск по почте, **Telegram ID** (его можно узнать у @userinfobot), коду
  друга или ID. Карточка: доступ, устройства, способ входа; кнопки «Продлить доступ»,
  «Отозвать доступ», «Заблокировать», «Роли», «Бонусные дни»; платежи, игра и журнал по
  человеку. Сам Telegram ID в панели не показывается — только ищется.
- **Платежи** — все счета @CryptoBot со статусом, суммой, монетой и скидкой.
- **Тарифы и цены** — цены не редактируются: добавьте новую и выключите старую.
- **Промокоды** — скидка в %, скидка суммой или бесплатные дни (как инвайты).
- **Серверы** — подключить сервер (токен показывается один раз), разгрузить, отключить,
  сменить токен; нагрузка, связь, версия агента и ошибки. Локации можно скрывать.
- **Блэкджек** — переключатели, подозрительные результаты, столы, события.
- **Прогресс и сезоны** — игроки по XP (поиск, фильтр «исключённые»), карточка игрока с уровнем,
  статистикой, достижениями, заданиями, сезонами и историей XP; **исключить из рейтингов** при
  подтверждённой накрутке (с причиной, можно вернуть). Сезоны: текущая таблица и итоги, создать
  событие, изменить, завершить досрочно (награды выдаются один раз). Достижения и задания дня:
  включить/выключить, изменить, создать. «XP и награды»: сколько XP за партию, кривая уровней и
  титулы, награды сезонов и серии дней, минимум партий для рейтинга по % побед. Бонусные дни
  VPN за игру выключены до проверки юристом.
- **Настройки** — все настройки сервиса с описанием и значением по умолчанию.
- **Журнал действий** — кто, что и когда менял. Каждое изменение в панели требует причину.
