# ADR-018 — KingKong VPN Mini App: traffic dashboard, referrals, ranks, country switch

Status: accepted (2026-11-13).

1. **Traffic accounting = aggregate bytes per device per UTC day** (`device_usage_daily`), computed
   from WireGuard's cumulative per-peer counters the agent reports in each heartbeat. Counter resets
   (peer re-added) are handled; rows are purged after 90 days (ADR-010). No destinations, no DNS.
2. **No "top apps" in the Telegram Mini App.** The server sees only encrypted packets per device and
   by policy records no destinations; neither Telegram nor a web page can see which app on the phone
   produced traffic. The dashboard shows the top 5 *devices*. Per-app usage is planned for the
   native Android app (on-device `NetworkStatsManager`, data stays on the device); iOS offers no
   such API to third-party apps.
3. **Referral program (v2, migration 0006):** personal link `t.me/<bot>?start=ref_<code>`; the
   referrer is attached only before the invitee's first payment.
   - The **invited user** gets `referrals.percent_off` (default 30 %) off their **first** payment,
     applied automatically at checkout (`payments.referral_percent_off`); not combined with a promo
     code. If the invoice expires the discount stays available until they actually pay once.
   - The **referrer** gets `referrals.bonus_days` (default 14, 0 = off) free days per invitee whose
     first payment succeeds: the live subscription is extended on its current plan; a referrer on
     a trial or with no subscription gets the plan the invitee bought. Suspended/deleted referrers
     get nothing. No discount for the referrer.
   - One credit per invitee (`referral_rewards`, unique `referred_id`) — a repeated webhook/poll
     can't add days twice. Toggle the whole program with `referrals.enabled`.
   - Known edge: an invitee with two unpaid discounted invoices open at once could pay both at
     the discount (bounded by `payment_pending_limit_per_user`).
3a. **Referral ranks** (`referrals.milestones`, migration 0007), counted by invited users who
   **paid** (empty sign-ups don't count): 🦊 Sly Fox at 3 (+7 days, theme "Lava"), 🕶 Hacker at 5
   (+30, "Matrix"), 👑 Ambassador at 10 (+90, "Gold"), 🚀 Legend at 25 (+365, "Cosmos"); below 3 —
   🐣 Chick. Each gift is given once (`referral_milestones`, unique (user, level)), on top of the
   per-friend days, with a Telegram/email notice. Themes are cosmetic: the server lists unlocked
   ones, the choice is kept in the device's local storage; the Mini App shows confetti once per
   new rank. The referrer's row is locked while crediting so concurrent payments by two friends
   count one after the other. Levels live in `app/services/referrals.py` (`LEVELS`).
4. **Country switch keeps the device key:** the Mini App stores each private key it generated in
   the device's own `localStorage` (never sent anywhere) so a device can be moved to another
   country and its config re-issued; devices created elsewhere get a new connection instead.
   Removing a device wipes its stored key.
5. **Brand: "KingKong VPN"** (renamed from the working name "VpnHub", 2026-11-13). Jungle look:
   black & green palette, leaves/vines backdrop (`miniapp/src/assets/jungle.svg`), the owner's
   gorilla patch as the logo (`miniapp/src/assets/logo.png`; bot avatar and 512 px icon in
   `branding/`). Rank display names follow the jungle (Monkey → Parrot → Jaguar → Gorilla →
   King Kong; themes Volcano, Night, Banana, Orchid); the stored codes (`fox`, `hacker`, …) stay.
   "King Kong" is a well-known film franchise name with trademark registrations, so the name
   should be cleared by a trademark lawyer before a public launch; it is set in one place per
   component (`APP_NAME`, `miniapp/src/index.html` data-app-name).
   Jungle dressing lives in `miniapp/src/jungle.js` + `style.css`: layered backdrop (palms,
   monstera, ferns, vines — generated by `miniapp/tools/jungle.py`), swaying edge vines,
   fireflies, a leaf wreath around the hub. **Page changes:** a monkey swings across on a vine,
   left → right when a section opens and right → left on "back", and the new screen slides in the
   same way; a plain refresh of the home screen doesn't animate, and nothing moves when the
   system asks for reduced motion. All decoration is `pointer-events: none` and sits behind the
   content (the swing overlay is above it for about a second).
6. **Clickable demo** (`miniapp/demo/`): the real Mini App bundled with a stand-in for Telegram
   and the API (sample data, scenarios, "+1 friend paid"), for showing the UI without a server.
   It never ships to production.
