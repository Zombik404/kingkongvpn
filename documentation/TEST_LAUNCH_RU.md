# Запуск тестовой версии в Telegram

Тестовая версия — это один сервер, на котором работает всё сразу:
- VPN (WireGuard);
- сайт мини-приложения с HTTPS;
- API, база данных и Telegram-бот.

Тест закрытый: войти можно только по инвайт-кодам. Оплата идёт через @CryptoBot в тестовой сети, монеты там ненастоящие.

**Что получит тестер:** открывает бота → «Открыть VPN» → вводит инвайт (по ссылке он подставится сам) → «Добавить устройство» → сохраняет конфигурацию → подключается в приложении WireGuard.

---

## Что понадобится

| Что | Где взять | Стоимость |
|---|---|---|
| VPS с Ubuntu 24.04 в ЕС | Hetzner, DigitalOcean, Vultr и т. п. Минимум 2 vCPU, 2–4 ГБ RAM, публичный IPv4. IPv6 желателен | Несколько евро в месяц |
| Адрес для HTTPS | Бесплатный поддомен на [duckdns.org](https://www.duckdns.org) или свой домен | 0 € (DuckDNS) |
| Токен бота | @BotFather → `/newbot` | 0 |
| Токен оплаты (тестовая сеть) | @CryptoTestnetBot → Crypto Pay → Create App | 0 |

Токены никому не пересылайте. Они вводятся только на сервере, во время установки.

## Шаг 0. Оформление бота

В @BotFather: `/setuserpic` → выберите бота → отправьте картинку `branding/bot-avatar-640.png` (значок KingKong). Там же `/setname` → «KingKong VPN».

## Шаг 1. Сервер

1. Создайте SSH-ключ на компьютере. В PowerShell выполните `ssh-keygen` и нажимайте Enter. Публичный ключ появится в `C:\Users\<вы>\.ssh\id_ed25519.pub`.
2. В панели хостинга создайте сервер: **Ubuntu 24.04**, страна в ЕС, добавьте этот публичный ключ.
3. Запишите IPv4-адрес сервера.
4. В панели хостинга, если там есть файрвол, разрешите только:
   - TCP 22, 80, 443;
   - UDP 443 и 51820.

## Шаг 2. Адрес (DuckDNS)

1. Зайдите на [duckdns.org](https://www.duckdns.org) через Google или GitHub.
2. Придумайте поддомен, например `myvpn-test`, нажмите **add domain**.
3. В поле **current ip** впишите IPv4 сервера и нажмите **update ip**.
4. Ваш адрес: `myvpn-test.duckdns.org`. Через минуту-две проверьте в PowerShell: `nslookup myvpn-test.duckdns.org`. Должен отвечать IP сервера.

С собственным доменом сделайте вместо этого A-запись на IP сервера.

## Шаг 3. Скопировать проект на сервер

В PowerShell на своём компьютере:

```powershell
scp -r C:\Users\timao\Desktop\global-vpn root@IP_СЕРВЕРА:/opt/globalvpn
```

## Шаг 4. Установка (одна команда)

```powershell
ssh root@IP_СЕРВЕРА
```

```bash
sed -i 's/\r$//' /opt/globalvpn/deploy/*.sh      # на случай переносов строк Windows
bash /opt/globalvpn/deploy/install.sh
```

Скрипт задаст несколько вопросов:
- адрес из шага 2;
- IP (обычно определяется сам, просто нажмите Enter);
- токен бота;
- имя бота без @;
- токен @CryptoTestnetBot (Enter, если оплату пока не тестируете);
- страну и город сервера.

Дальше скрипт всё сделает сам: установит Docker и WireGuard, настроит файрвол, соберёт и запустит приложение, получит HTTPS-сертификат, зарегистрирует сервер как VPN-узел и запустит агента. В конце он покажет **10 инвайт-кодов со ссылками** вида `https://t.me/ваш_бот?start=INV-XXXX-XXXX`. Первая сборка занимает 5–10 минут.

Скрипт можно запускать повторно: секреты и ключи сохраняются.

## Шаг 5. Проверить самому

1. Откройте своего бота → `/start` → **Открыть VPN**.
2. Введите инвайт-код → **Активировать**. Появится «Активен до …».
3. **Добавить устройство** → **Создать подключение**:
   - **на компьютере**: «Скачать .conf» → WireGuard → Import tunnel(s) from file;
   - **на телефоне**: отсканируйте QR-код с экрана компьютера в приложении WireGuard (Telegram Desktop тоже открывает мини-приложение). Другой вариант — «Открыть в браузере» → «Скачать файл» → открыть файл в WireGuard.
4. Включите туннель и проверьте:
   - [ ] [ifconfig.me](https://ifconfig.me) показывает IP сервера;
   - [ ] [dnsleaktest.com](https://www.dnsleaktest.com) не показывает DNS вашего провайдера;
   - [ ] [test-ipv6.com](https://test-ipv6.com) показывает адрес сервера или отсутствие IPv6, но не ваш домашний IPv6;
   - [ ] удаление устройства в приложении отключает интернет в туннеле за несколько секунд.
5. Оплата (если вводили токен @CryptoTestnetBot): выберите тариф → откроется счёт в @CryptoTestnetBot → оплатите тестовыми монетами → в приложении появится «Оплата получена». Тестовые монеты выдаёт сам @CryptoTestnetBot, смотрите его меню.

## Шаг 6. Позвать тестеров

Отправьте каждому его личную ссылку из списка. Каждый код одноразовый и даёт 30 дней. Список хранится на сервере в `/etc/globalvpn/invites.txt`.

Создать ещё коды:

```bash
cd /opt/globalvpn/deploy
docker compose -f docker-compose.prod.yml --env-file .env.prod exec backend \
  python -m app.cli create-invites --count 5 --days 30
```

Кроме инвайтов, у каждого пользователя есть реферальная ссылка (кружок «Друзья» в приложении). Пока тест закрытый, приглашённому по ней всё равно нужен инвайт-код. Друг, пришедший по ссылке, получает скидку 30% на первую подписку, а пригласивший — +14 дней VPN бесплатно, когда друг оплатит. Настройки: `referrals.percent_off` и `referrals.bonus_days` (0 — без бонусных дней).

Ранги за друзей с подпиской: 🦊 3 — +7 дней и тема «Лава», 🕶 5 — +30 дней и «Матрица», 👑 10 — +90 дней и «Золото», 🚀 25 — +365 дней и «Космос». Выключить: настройка `referrals.milestones`.

## Полезные команды (на сервере)

```bash
cd /opt/globalvpn/deploy
alias dc='docker compose -f docker-compose.prod.yml --env-file .env.prod'

dc ps                                 # что запущено
dc logs -f backend bot worker         # логи приложения
journalctl -u globalvpn-agent -f      # лог VPN-агента
wg show                               # пиры WireGuard и рукопожатия
dc exec backend python -m app.cli cryptobot-check            # проверить @CryptoBot
dc exec backend python -m app.cli set-price standard month 1 USD 5.00   # поменять цену
```

**Обновление:** скопируйте новые файлы проекта (шаг 3) и снова запустите `install.sh`.

**Бэкапы базы:** каждый день в `/var/backups/globalvpn`, хранятся 14 дней. Время от времени копируйте их к себе: `scp root@IP:/var/backups/globalvpn/* .`

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Мини-приложение не открывается, ошибка сертификата | `nslookup ваш-адрес` должен давать IP сервера; затем `dc restart caddy`; `dc logs caddy` |
| «Не удалось войти через Telegram» | Токен бота в `.env.prod` должен быть от того же бота; перезапустите `install.sh` |
| «Сейчас нет доступных серверов» | `systemctl status globalvpn-agent`, `journalctl -u globalvpn-agent -n 50` |
| Туннель подключён, но интернета нет | `wg show`: есть ли рукопожатие? `systemctl status globalvpn-firewall`; в панели хостинга открыт UDP 51820? |
| Оплата не подтверждается | `dc exec backend python -m app.cli cryptobot-check`; `dc logs worker` |

## Чего в тестовой версии нет

- реальных платежей (сейчас тестовая сеть @CryptoBot);
- собственных приложений и сайта;
- нескольких стран и автомасштабирования;
- мониторинга с оповещениями;
- писем на email: аккаунты привязаны только к Telegram;
- юридических документов (политика конфиденциальности — до публичного запуска).
